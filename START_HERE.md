# village game web (started 14 Sep 2026)

Web version of Dopahar (village: Amrai Khera). three.js + Vite, opens on a link, phone and desktop.
The Unity project lives in ../Village nostalgia and is NOT deleted. It is the future downloadable version.

## Folders
- Places V1/        2D place references from Gemini (hero sheet + ortho sheet per place). LAYOUT.md in each = authority for counts, names, sizes.
- Characters V1/    2D character references. Stylised set is being regenerated as *_real.png (photoreal) before Tripo.
- Mood board/       1.png is the true taste reference.
- reference-from-unity/   Copied docs from the Unity project. Read-only history, not rules for this repo:
    docs/art-direction.md   section 7.0 = the look decision (grounded realism, mid-distance)
    docs/collaboration_lessons.md, decisions-made.md, licences.md, performance_budget.md
    CHARACTER_BIBLE.md, MAP.md, CONTEXT.md, WorldData/*.json (hero zone positions, 1 unit = 1 m)
    ambientcg/  CC0 textures already downloaded
- tools/            fetch_assets.py (CC0 downloader), tripo_batch.py

## Rules carried over (non-negotiable)
- No real brands, logos or real village names. No tobacco or alcohol. Era: nothing post-~2015.
- Ordinary and mixed village like Panchayat: intact, sun-faded, lived-in. Never peeling, cracked, exposed brick, poverty-porn.
- Signboards bilingual: Devanagari larger, English beneath.
- Assets: CC0 first, CC BY second (credited in docs/CREDITS.md), NC never. Unknown licence = not used.
- Camera mid-distance, no face close-ups. One fixed late-afternoon light.
