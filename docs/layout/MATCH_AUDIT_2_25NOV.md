## Method and script check (what export2.mjs got wrong, fixed in export3.mjs)

- export2.mjs took shop positions from `getLayout().objects[].rect` (mapData.json pack + src/layout/shopRects.json). At runtime shopsPlace.js is fed `loadLandMap()` = the RAW approved map (vite landMapPlugin; landLayout.js header: raw objects have 0 `.rect`), so shopRects.json never reaches shopsPlace.js (it only feeds getLayout() consumers). export3.mjs therefore uses the runtime path: raw ring + raw place front via ringRect/matchPlace, ring-fallback front for far-marker kiosks/carts/sqx, nearest-road front for the shopkeeper home (sqh), plus the current put() stand-slide for kiosks/carts/sheds (slides only if a stand is > 1 m into a band; none needed this run unless noted).
- The old nudgeOffRoad (bounding circle) is not applied. Railway station, platform shelter and waiting hall are skipped by shopsPlace.js and built by src/kit/railway.js straight from the raw ring bounding box (axis-aligned), so they are audited at the exact ring.
- The 17 prop nudges live only in mapData.json (pack). landProps.js reads raw `map.objects` (un-nudged), the planner (mapObjectsPlan.js) reads the pack. So landProps items (signs, washing lines, wells, pumps) are at the map spot, planner items (milestones, pots) at the nudged spot. Not confirmed in a render.
- Houses: built = src/kit/housesPlanData.json rows. Roads: src/mapRoads.js allRoadLines + filletPolyline (cap 0.2 m).
