# Signboard inventory, 26 Nov 2026

Read-only inventory of every lettered board, sign and painted name in the game, built from the source on 26 Nov (default layout = `?layout=new`). Wall posters (`src/kit/wallPoster*.js`, and `src/kit/wallMurals.js`, which paints the same poster atlas) are NOT included. The CSV `docs/signboard-inventory-26nov.csv` holds the same rows with every column (full "made by" text, colours, borders).

- **Systems (made by code)**: PB = `src/placeBoards.js` (35 ids, one BatchedMesh, 640x145 cells); WA = `createWideSignAtlas` (1024x232 cells, `src/signboards.js`); WA512 = same at 512x116; HERO = `buildSignboards` tea stall and general store; BZ = bazaar own atlas (1024x256); SH = map shops (`src/kit/shopsSigns.js`, 2048 px atlas, 5 shapes); MS = map post signs (`src/kit/mapSigns.js`); WF = wayfinding (`src/wayfinding.js`); MG = highway-end boards (`src/mapGates.js`); MO = welcome gate and notice board (`src/kit/mapObjectsSigns.js`); LP = village name stone (`src/kit/landProps.js`); ZM = zero milestone; TH = tea thela; DN = donation board; CE = tractor tail board; WW = wall writing; VF2 = school/anganwadi wall paintings; CR = classroom blackboard and charts; BL = blank board mesh inside a Blender GLB.
- **Under the default layout (layout=new) these builders are OFF**: `armFrontage`, `mainRoadFrontage`, `chaurahaEdges`, `vendors`, `vendors2` (all old-layout), `gullyLife` places nothing (its two lanes `20_Council lane` and `21_Lane east of the square` do not exist in the approved map), `newShops.buildNewShopSignboards` is never called, and the farmSites legacy dairy, chemist, manihari, khel maidan and gurukul boards are not built (v2 yards stand).
- **Not lettered, so not listed**: the 9 map milestones and 4 east-road stones (`milestone_v2*.glb`, no lettering, only the zero milestone carries text), house name plates (`src/houseExtras.js`, blank 0.5x0.26 plate with two dark lines), product packaging text in `src/shopGoods.js` (packs and soaps on shop shelves), UI text.
- **Items I could not size exactly**: thela cart boards (width ~1.73 m / height ~0.39 m assumed from the 2.4 m cart length; mount height depends on the GLB bounding box at runtime), the 9 wall-writing decals and 2 school wall paintings (size known, exact wall position is found at runtime by name), the tractor tail board (moves with an event), the 14 Blender blank boards (model units; some shells are scaled afterwards, see notes), the vendors/chauraha/arm rows (counts depend on layout=old scatter).
- **Code issues found while reading**: (1) `src/vendors.js:525` has `signGeo.rotateY(...)` and `signGeo.translate(...)` inside a `//` comment, so the tailor board would sit at the world origin (only matters under layout=old). (2) `buildSignboards` boxes are 3.6x0.5 and 2.9x0.55 but the atlas cell is 4.41:1, so those two hero boards stretch the lettering. (3) `src/placeBoards.js` comment says faith buildings carry no board, yet `masjid` and `gurudwara` name boards are placed (`src/farmSites.js:998,1025`). (4) Blender blank boards and PB overlays disagree in size for panchayat (3.6 vs 2.6 m), ration (3.3 vs 2.6), post (3.8 vs 2.6), dairy slogan band (4.0 vs 2.55). (5) `PLACE_BOARDS` ids `petrol`, `kanta`, `station` have no placement.

## 3. Design constraints for the replacement

### Language and paint (CLAUDE.md section 7, 25 Oct final call)
- **Line 1 Hindi (Devanagari), bold, larger**; **line 2 English, not bold, smaller**, English cap height 60-70% of the Hindi cap height, never below 55%.
- **Same dark paint for both lines** on a pale ground; never pale grey English on a pale board. Fail test: English must read at normal walking distance (the project checks at 8 m).
- Painting lives in ONE function, `drawBilingual(ctx, hi, en, {x, y, w, h, fg, align, maxHiPx, fillFraction, gapFraction, set})` in `src/signPaint.js`; boards that call it inherit the rule automatically. Font sets: `noto` (default) and `yatra`, `rozha`, `kalam`, `teko` (only the map-shop atlas picks these).
- UI text elsewhere stays English-first; painted world signage is Hindi-first. Do not flip it.

### Content rules
- **No real brands, logos or wordmarks. No real village names** (the game village is "Amrai Khera"; the map file spells the station "Amrai Kheda" and `EN_FIX` in `src/kit/mapSigns.js` corrects it).
- **No alcohol, tobacco or intoxicants.** The only paan board is `Paan Bhandar` in `src/vendors2.js` (off under layout=new); avoid it or rename. No paan, gutkha or cigarette words anywhere.
- **Era before about 2015.** No UPI/QR, no smartphone brands. Mobile and recharge shops, cyber cafe, CD and cassette are fine.
- **Faith buildings carry no commercial board.** Temple, Jain mandir: no board at all. Masjid and gurudwara currently carry a plain name board (`masjid`, `gurudwara`); the file comment says they should not, so confirm with the art director before copying that. Zero tasks at faith buildings.
- No party names or symbols on wall slogans (current ones use a plain sun or star). No personal data or real notices.
- Names are written by us; her place images carry no lettering. Spelling comes from the code tables, never from reference images (the bazaar `LAYOUT.md` records garbled English in the images).

### Aspect ratios and sizes to keep so nothing else needs to change
- **placeBoards**: cell **640x145 (4.414:1)**; world size `w x (w*145/640) x 0.06`; default `w = 3` (3.0 x 0.68 m). Placed widths in use: 1.4, 2.2, 2.4, 2.55, 2.6 (x3), 2.9, 3.0, 3.2, 3.4, 3.6, 3.8, 4.0, 4.2, 4.4, 4.8, 4.9, 5.2, 6.4, 7.2 m. Keep the **front face = +z** and the thin box, so the batched mesh and `mapFrontFaceToRow` keep working.
- **createWideSignAtlas** boards (smallShops, milk centre, gully, arm, main road, chauraha, vendors, newShops): cell **1024x232 (4.414:1)** or 512x116 (same ratio); boards are `w` x `w/4.41` x 0.03-0.04. Hero tea stall and general store use boxes 3.6x0.5 and 2.9x0.55 (7.2:1, 5.3:1) on a 4.41:1 cell, so a replacement should either fix the box to 4.41:1 or paint the cell at the box ratio.
- **Bazaar**: cell **1024x256 (4:1)**, board `4.0 x 1.0 x 0.04` m at roof level (`wallHeight + 1.02`), 8 units plus the (unused) chowk tea board.
- **Wayfinding**: cell **1024x256 (4:1)** per direction board, `1.5 x 0.375` m face on a `1.56 x 0.435 x 0.05` slab; notice board face 1.7 x 1.7 (1024x1024). Text is computed from `PLACES` (name, arrow side, distance) so the painter must keep that call.
- **Map shops**: 512 px wide cells in 5 shape shelves of height **92, 128, 160, 198, 240 px** (ratios 5.57, 4.0, 3.2, 2.59, 2.13); 4 columns x 2048 px atlas; world board `h in [0.55 s.h, 1.7 s.h]`, `w = h * 512/ch`, thickness 0.03-0.075. Rows per shape: 10, 14, 10, 8, 6 columns x 4. Cell key = name + scheme (14) + layout (centre/left/right); 14 colour schemes, 5 styles (enamel, tin, wall, banner, photo).
- **Map post signs**: atlas cell height **128 px, width = 128 * w / bh**; board `w` (rect width from the map) x `bh = clamp(w/3.6, 0.8, 1.25)`, top at y 3.05, 0.07 thick, two 0.14 m posts 3.2 m tall. 115 boards, atlas 4096 wide.
- **Highway end boards**: canvas 1536x460 on a 3.0 x 0.9 plane; **welcome gate** faces 1024x200 on a 7.2 x 1.4 plane; **notice board** cell 600x404 on a 1.84 x 1.24 plane; **zero milestone** 4 faces 1.09 x 0.62 (canvas 1024 x 582); **thela** 1024x232 on a ~1.73 x 0.39 plane; **donation board** 900x520 on 3.0 x 1.73 box.

### How the current boards are referenced in code (drop-in points)
- **PB boards**: by string id. Edit/add a row in `PLACE_BOARDS` in `src/placeBoards.js` (`{ id, hi, en, fg, bg?, border? }`); the atlas row is the array index (`ROW` map). Placement is `{ id, x, y, z, ry = 0, w = 3 }` in the place group: `src/stagedPlaces.js` (`boards:` arrays), `src/farmSites.js` (`boards:` and `parapetBoard(id, {w,d,h}, bw)` = y `0.35 + h + 0.5`, z `d/2 + 0.24`), `src/main.js:679-682`, `src/stagingYard.js:250`, `src/kit/railway.js:184` (currently an empty list). A new look can replace the atlas painter in `createWideSignAtlas` once, or add per-id fields like `bg`/`border` (already supported).
- **WA atlases**: each builder passes `[{ hi, en, bg?, fg?, border? }]` to `createWideSignAtlas`; the row index is used by `mapFrontFaceToRow(geo, row, rows)` (face `+z`, group 4). Rows: smallShops `book, cd, mithai` (0-2), milkCentre 0, gully/arm/main/chauraha rows by `SIGNS` key order, hero `buildSignboards` rows 0-1 (tea, store); the shared canvas copy goes through `addToSignHub(slot, texture)` (`src/signAtlasHub.js`, slots `hero`, `bazaar`, `newShops`, `donation`).
- **Bazaar**: atlas cells by unit index `idx` (col = idx % 2, row = floor(idx/2)); front face is `-z`. Text lives in `BAZAAR_UNITS[].hi/.en` (`src/bazaar.js:49-56`).
- **Map shops**: `atlas.cell(signName, schemeIdx, shapeIdx, layout)` in `src/kit/shopsPlace.js:117-130`; Hindi names come from the `HINDI` table in `src/kit/shopsSigns.js` (about 100 English keys), painter is `paintBoard`; a replacement can swap `paintBoard` and keep `uv(cell)` and `boardGeometry`.
- **Map post signs**: Hindi from the `HI` table in `src/kit/mapSigns.js` (keyed by the map name after "Signboard: "); `EN_FIX` renames. Atlas painted in `initMapSigns` (shelf-packed).
- **Others** have their own text constants next to the painter: `src/mapGates.js:117`, `src/kit/mapObjectsSigns.js:20-36`, `src/kit/landProps.js:55-56`, `src/zeroMilestone.js:30-31`, `src/thelaSign.js:12-13`, `src/props.js:223-232`, `src/cyclistEvents2.js:99`, `src/wallWriting.js`.
- **Validator hooks**: materials named `signboard` are exempt from the ground-contact check (`tools/world-validator.js`); keep that material name for any new wall or roof board. Tools that read the batch: `tools/collision-test.js` (`place_boards_batch.userData.pairs`), `tools/signboard-8m-check.mjs` (hero boards).
- **Blank Blender boards** (BL rows) are the physical backing for the PB overlays; if the replacement changes a board size, change the `wb(...)` call in the owning `tools/blender/build_*.py` and rebuild the GLB, or keep the overlay inside the blank.
